Open-source tools for AI agents and retrieval

n24q02m Lab is an independent, self-funded software lab. It builds and maintains open-source tools for AI agents, retrieval and inference runtimes, and the developer infrastructure around them.

What we work on

Retrieval and inference

Embedding, reranking and multimodal retrieval runtimes that run on ordinary CPUs and GPUs.

Agent tooling

Command-line tools with MCP servers for web search, persistent memory, code review and workspace apps.

Efficient, auditable AI

Research on lowering the cost of model reasoning while keeping every answer checkable.

Developer infrastructure

Release, packaging and secret-management tooling shared across the projects.

Open source

Projects, releases and publications are developed in the open on GitHub.
